# 已知限制与后续计划

> 当前版本定位：可受控试点的生产候选版本。公网已切换到 `wecraft-pilot`，演示账号已停用。<br>
> 这不是生产终态；下列限制在正式上线前必须逐项关闭或由业务负责人书面接受。

## 2. 功能限制

- 长任务仅有类型筛选，尚未提供真正的批量分配和可保存视图。
- 案例/反例导入表单已结构化，但没有完整的 CSV/Excel 批量导入与校验报告。
- 盲测支持 A/B 与 TIE 结果记录；尚未提供跨实验的批量统计导出和管理员重跑工具。
- 仪表盘已提供核心指标，但尚无可配置时间窗口、维度下钻和指标口径管理页。
- 法律冻结在数据模型和部分服务端约束中预留，但尚无完整管理 UI 与专项 E2E。
- 通知中心支持站内已读；没有消息偏好、摘要订阅和升级提醒。
- 无密码找回、MFA、账号自助注销和企业 SSO 通用适配。
- 当前界面面向桌面端，375px 仅用于查看案例截图，不支持移动端编辑后台。

## 3. 运行与安全限制

- 硬检查在 Web 进程内同步启动 Chromium，没有独立任务队列、超时回收和隔离 runner。
- Chromium 通过 `--no-sandbox` 启动，依赖容器/虚拟机边界。生产环境应使用独立 runner、只读文件系统、资源配额和网络出口白名单。
- `sanitize-html` 允许内联 `<style>` 以还原设计，因此会触发库的安全警告。当前通过 CSP、外部 URL 清理和 `sandbox=""` iframe 阻断脚本与网络，但样式仍可能影响预览区域外观。
- 审计哈希链能发现断链和单条篡改，但不是外部 WORM 存储；拥有数据库全量写权限的人理论上可以重建整条链。生产应定期把链头锚定到不可变存储或外部日志服务。
- 数据集 ZIP 下载链接是短期授权下载，不是公开预签名 URL；大文件场景需要流式下载和断点续传。
- 已内置账号/IP 登录节流，但没有 MFA、企业 SSO、WAF 或 IP 允许列表；当前稳定公网只应向团队受控分发地址，真实授权证据仍应限制在受控网络内。
- 无密钥轮换自动化和密钥管理系统集成；生产必须使用云 KMS 或 Secret Manager。

## 4. 数据与运维限制

- 已有每日 PostgreSQL 逻辑备份、SHA-256 校验、30 天保留和隔离恢复演练；副本已写入独立私有 OSS Bucket，并从 OSS 重新下载完成异地恢复演练。当前 RPO 最长 24 小时，且 Bucket 与主机仍在同一云账号，尚未实现跨云灾备。
- 没有 HA、读写分离、数据库连接池上限调优和容量规划。
- 没有压力测试结果。建议上线前验证 1,000 案例、20 并发评审和 500 条数据集导出。
- 已有 5 分钟健康、容器、磁盘和备份新鲜度巡检，飞书告警已接入并完成送达测试。5xx 率、硬检查 ERROR、导出失败和审计写入失败仍需接入指标平台。
- 训练平台与 WeCraft 生产共用 ECS 和 Docker daemon。2026-11-14 已发生并发构建导致训练镜像/容器被清理、以及 17:04 训练容器被外部停止的事故；目前通过共享 `/run/wecraft-release.lock`、固定 revision 镜像和离线镜像归档降低风险，但正式生产仍应迁移到独立主机或独立 Docker daemon。
- Dockerfile 与 Docker Compose 已在 Ubuntu 22.04 稳定公网 Stack 实测；本次 Windows 开发机未运行容器。
- GitHub Actions 已覆盖 PostgreSQL 迁移、typecheck、单测、生产构建和 E2E；尚未覆盖 Docker 镜像构建、公网部署冒烟和压力测试。
- 正式试点空间当前没有真实优质案例、反例、黄金 Brief 或 Holdout pair；Owner 也是当前唯一真实账号。不能把演示数据或功能冒烟当作试点数据已就绪。

### Render Free 限制

以下限制仅适用于备用 Render Free 方案；当前稳定地址与 Docker 验收见[稳定公网部署](operations/stable-public.md)。免费实例有以下硬限制，正式协作前必须接受：

- Web 服务 15 分钟无请求自动休眠；免费文件系统在休眠/重启后丢失，因此平台使用 PostgreSQL 文件存储。
- 不支持持久盘、SSH/Shell、one-off job 和后台 worker；单实例运行。
- 每月 750 免费实例小时，单实例；超出后服务不可用直到下月。
- 免费 PostgreSQL 每 Workspace 仅 1 个、1 GB、无备份、无连接池、可能维护重启。
- 免费 PostgreSQL 创建 30 天后过期；到期后需升级付费、迁到其他数据库或重建演示环境。重建会丢失所有平台数据。
- Render Free 公网地址为 `onrender.com` 子域，不绑定自定义域名；冷启动可能耗时数十秒。

因此该实例定位为“免费演示/轻量验收”，不是长期生产环境。真实案例导入前应先落实备份和长期数据库方案。

## 5. 依赖与升级

截至 2026-11-12，`npm audit` 报告 13 个漏洞：

- 6 个 moderate
- 7 个 high
- 0 个 critical

直接依赖中的主要升级项：

| 包 | 当前版本 | 建议修复版本 | 影响 |
| --- | --- | --- | --- |
| `next` | `15.5.29` | `16.4.6` | 间接 PostCSS 高危项；需要大版本回归 |
| `prisma` / `@prisma/client` | `6.19.0` | `7.10.1` | 配置与深层依赖升级；需要迁移评估 |
