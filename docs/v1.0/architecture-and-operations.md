# WeCraft 设计训练协作平台 技术架构与运营方案 v1.0

> 状态：冻结候选。本文给出默认技术选型、部署、数据治理、安全、审计、备份和 4–6 周实施建议；不替代安全评审与法务结论。

## 1. 结论

- 独立部署的内部 Web 应用，不改 WeCraft 生产代码、数据库或发布流程。
- 默认栈：Next.js + Fastify REST + PostgreSQL + Prisma + S3/OSS；异步任务用 Postgres 队列；HTML 预览用独立沙箱渲染服务。
- 单租户 Workspace 起步，数据模型保留 `workspace_id`，未来可扩多 Workspace；不引入微服务拆分。
- 沙箱与主应用网络隔离：无脚本、无外部请求、无持久 Cookie、CPU/内存/时间限额。
- 审计只追加、授权可撤回、导出可追溯、备份可恢复是上线硬门槛，不是“后续优化”。

## 2. 技术选型

| 层 | 默认选型 | 理由 | 等价方案 |
| --- | --- | --- | --- |
| Web | Next.js（App Router）+ TypeScript | 桌面优先、表单/评审界面成熟；SSR 便于权限与首屏 | Remix、Vite + React |
| API | Fastify + REST + Zod | 外部候选写入、审计和错误码清晰；比纯 tRPC 更适合非前端调用 | tRPC（仅内部）、NestJS |
| DB | PostgreSQL 16 | 事务、JSONB、部分索引、行级约束适合评审/授权/数据集 | 兼容 PostgreSQL 的托管服务 |
| ORM | Prisma | 迁移、类型安全、关系清晰 | Drizzle、Kysely |
| 队列 | pg-boss（Postgres） | MVP 不引入 Redis；硬检查/导出/通知可重试、可观测 | Redis + BullMQ |
| 文件 | S3 或阿里云 OSS 私有桶 | 版本、生命周期、签名 URL、KMS | MinIO（仅开发） |
| 预览沙箱 | Playwright + Chromium 独立容器 | 真实 375px 渲染、截图、可测 CSP/网络隔离 | Puppeteer、托管渲染服务 |
| 登录 | 飞书 OAuth + 邮箱密码（Argon2id） | 满足飞书优先与审批期降级 | 企业 SSO（P2） |
| 通知 | 站内通知 + 飞书机器人适配器 + 邮件适配器 | 飞书未批不阻塞；消息最小化 | 企业微信/钉钉适配器 |
| 可观测 | OpenTelemetry + 结构化日志 + 指标/告警 | 审计之外的运行可观测性 | 云厂商监控 |
| 部署 | Docker + 内部 K8s/ECS；托管 PostgreSQL | 内网访问、滚动发布、隔离沙箱 | 单机 Docker Compose（仅试点） |

不选：模型训练/推理服务、向量数据库、实时协同（CRDT）、复杂排名模型、公开 API 市场。它们不解决 v1 的授权、评审和导出问题。

## 3. 部署拓扑

```text
内网用户 / 飞书 OAuth
        |
   Ingress (TLS, IP allowlist)
        |
  Web/Next.js  ---  API/Fastify  ---  PostgreSQL (managed, PITR)
        |                |                  |
        |                +--- pg-boss 队列  |
        |                +--- 邮件/飞书适配器
        |
  私有对象存储 S3/OSS (SSE-KMS, versioning)
        |
  沙箱渲染服务 (独立 namespace/子网, 无公网出口)
```

- Web/API 可同镜像不同进程；MVP 不拆微服务。
- 沙箱独立 Deployment/任务容器；只接收已扫描的 HTML 与资产引用，输出截图和检查结果。
- 数据库、对象存储不暴露公网；仅 Ingress 和飞书回调受限开放。
- 环境：`dev`、`staging`、`prod` 三套独立凭据；staging 使用脱敏种子数据。
- 生产 WeCraft 不连本平台数据库；如需读案例，仅通过人工导出/授权接口，不在本期实现自动同步。

## 4. HTML 预览与硬检查沙箱

| 控制 | 要求 |
| --- | --- |
| 源隔离 | 独立子域/独立 origin，不能读取主应用 Cookie/localStorage |
| iframe | `sandbox="allow-same-origin"` 不含 `allow-scripts`；禁止 top navigation/popup |
| CSP | `default-src 'none'; img-src 'self' data:; style-src 'unsafe-inline'; font-src 'self'; connect-src 'none'; script-src 'none'; frame-src 'none'` |
| 网络 | 容器无公网出口；DNS 禁用或指向黑洞；仅允许读取平台代理的内联资产 |
| 脚本 | 禁止 `<script>`、事件属性、`javascript:`、SVG 脚本、meta refresh |
| 资源 | 外链图片/字体/CSS 默认阻断；需要时先下载、扫描、改写为平台资产 |
| 运行限额 | CPU 0.5、内存 512MB、超时 10s、无持久卷；进程数限制 |
| 截图 | 375px 与桌面宽度；检查 `scrollWidth <= 376`；记录渲染器版本 |
| 上传 | MIME/扩展名/大小校验、病毒扫描、HTML 规范化、hash 固定 |

硬检查在沙箱内执行 HC-01…HC-13，治理规则 HC-14…HC-18 由流程服务校验。任何 BLOCK 失败不得进入盲测；例外只改变门禁，不修改原始结果。

## 5. 身份、会话与权限

- 飞书 OAuth 使用授权码 + state + PKCE（如飞书支持）；只申请 `open_id`、姓名、头像，邮箱可选；通讯录范围仅项目组/指定部门，不申请全量通讯录。
- 邮箱登录：邀请制，Argon2id 哈希，登录限流，失败不泄露账号是否存在。
- 会话：HttpOnly/Secure/SameSite=Lax Cookie；服务端会话表/Redis；空闲 8 小时、绝对 7 天过期。
- CSRF：写请求双提交 Token；CORS 默认关闭，仅白名单。
- RBAC：应用层强制 + 数据库复合外键/Workspace 校验；可选 PostgreSQL RLS 作为纵深防御。
- 高风险管理动作（授权、导出、法律冻结、破窗）要求二次确认和理由。

## 6. 数据治理

| 数据级别 | 示例 | 控制 |
| --- | --- | --- |
| 公开 | 已批准且 `canShowPublicly=true` 的案例摘要 | 仍需登录；不放公网 |
| 内部 | Brief、已批准案例、聚合指标 | 成员按角色读取 |
| 机密 | 未批准案例、候选 HTML、评审分数、模型信息 | 分配/角色限制；盲测白名单 |
| 受限 | 授权证据、合同、PII、审计、法律冻结 | OWNER/DESIGN_LEAD/ADMIN 最小必要；下载审计 |

- 数据分类在字段级执行；导出按数据集用途重新校验，不继承列表页缓存。
- 授权证据与案例同 Workspace；证据文件私有桶、短签名 URL、禁止公开 CDN。
- 评审人身份在导出偏好数据中使用 `reviewer_pseudonym`，不写姓名/邮箱。
- 数据保留按 F-22；法务未确认前不做不可逆物理删除。
- 供应商/云服务需明确数据地域、加密、子处理者；不把受限数据放入第三方分析工具。

## 7. 安全控制

| 领域 | 控制 |
| --- | --- |
| 传输/存储 | TLS 1.2+；数据库/对象存储静态加密；KMS 轮换 |
| 密钥 | 云 Secrets Manager/KMS；不入库、不进日志、不进前端 |
| 越权 | 每个请求 Workspace + 对象 + 分配 + 利益冲突校验；跨租户 404 |
| 注入 | 参数化查询/ORM；HTML 白名单清洗；输出编码 |
| SSRF | 沙箱无网络；服务端抓取仅白名单域、禁内网 IP、限重定向 |
| 上传 | 类型/大小/病毒扫描；HTML 存隔离桶；图片重编码 |
| 依赖 | 锁文件、SCA、镜像扫描、最小基础镜像 |
| 日志 | 不记录正文、HTML、授权证据、密码、Token；PII 脱敏 |
| 速率 | 登录、导出、盲测提交、API Token 限流 |
| 供应链 | 构建可复现、镜像签名、部署审批 |

上线前必须完成：越权测试、盲测泄漏测试、HTML 沙箱逃逸测试、导出权限测试、依赖/镜像扫描。

## 8. 审计

- `audit_logs` 只追加；应用数据库账号无 UPDATE/DELETE；写入与业务事务同事务。
- 记录：操作人/系统/Token、动作、资源、前后值（脱敏）、理由、请求 ID、IP/UA、时间。
- 关键动作：登录/邀请/角色、Brief 签收、案例/反例状态、授权变更/核验/撤回、评审提交/修订、裁决、硬检查/例外、实验/pair、盲测揭示、数据集批准/导出/下载/撤回、法律冻结/解除、破窗、备份/恢复。
- 审计链可用 `prev_hash/entry_hash` 校验；每日校验任务，异常告警。
- 保留 3 年；`OWNER/ADMIN` 可读全量，其他按 RBAC；审计导出本身写审计。

## 9. 备份与灾难恢复

| 项目 | 默认 |
| --- | --- |
| 数据库 | 托管 PostgreSQL 自动备份 + PITR；每日全量、持续 WAL |
| 对象存储 | 版本化 + 跨可用区冗余；删除保护；生命周期按留存 |
| 配置/密钥 | IaC 仓库 + Secrets Manager 备份；密钥轮换 |
| RPO | ≤15 分钟（TBD-RPO-RTO 确认） |
| RTO | ≤4 小时（TBD-RPO-RTO 确认） |
| 演练 | 每周隔离环境恢复；每月完整演练；上线前必须一次 |
| 校验 | 备份校验和、恢复后审计链、数据集 manifest/hash、授权快照 |

恢复流程：双人确认 → 隔离环境恢复 → 数据校验 → 安全/业务签收 → 切流。恢复不自动恢复导出权限；法律冻结与审计优先保全。

## 11. 运行与告警

- 指标：请求 p95、错误率、队列积压、硬检查失败率、导出时长、沙箱超时、飞书失败率、登录失败率。
- 告警：审计链异常、导出异常下载、盲测元数据异常访问、授权撤回、法律冻结、备份失败、存储 5xx。
- on-call：试点期工作日 9:00–19:00；S0 30 分钟内响应。
- 发布：staging 自动迁移 + 备份 → 生产滚动发布；数据库迁移向后兼容；回滚脚本与演练。
